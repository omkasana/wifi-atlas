# Security reporting

Do not post vulnerabilities, credentials, private network identifiers, or personal floor plans in public issues.

Email **omkasana28@gmail.com** privately, or use GitHub’s **Security → Report a vulnerability** option if enabled for this repository. Do not put exploit details in a public issue.

Include affected version/commit, reproduction steps, impact, and a minimal example with fictional or redacted data. Do not test against networks or devices you do not control.

The project is under active development. Fixes target the current `main` branch; older snapshots do not have a guaranteed security-maintenance window or response SLA. Source availability does not imply an audit or security certification.

The app uses public macOS APIs and stores history locally. Optional speed tests/public-IP lookups contact Cloudflare; network names can require Location Services permission. Signing keys, passwords, notarization profiles, local archives, and build products must never be committed.
